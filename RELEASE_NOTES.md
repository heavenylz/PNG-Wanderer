# PNG Wanderer v0.4 beta

Windows x64 desktop companions for your own PNGs and animated GIFs.

New: independent GIF pause, optional startup at Windows sign-in, monitor selection per companion, optional fullscreen quiet mode, and locally saved companion groups. Includes the native settings redesign and existing movement modes, sizing, speed and click-through.

Download PNG-Wanderer.exe, place it in a permanent folder and run it. Python is not required. Source is available separately. Startup and quiet mode are off by default.

Validation: automated regression suite and packaged offscreen GIF/settings smoke check. Physical multi-monitor, login startup and game/fullscreen compatibility remain beta test areas. EXE is unsigned. Groups reference local image files; keep originals in place. No uploads, telemetry or Steam integration.
