# PNG Wanderer

**A small Windows desktop companion for static PNGs and animated GIFs.** GIFs play their original frames, timing, transparency and loop settings through Qt QMovie. PNGs remain static.

This project is still in **beta** (`0.4.0-beta.1`) while Windows behavior is being tested.

## Features

- Import up to **12 PNG/GIF images** as independent desktop companions.
- Three movement modes: **Wander** (occasional direction changes), **Bounce** (fixed direction, reflect at edges), and **Follow cursor** (stops about 85 px from the pointer).
- Change **size** (48–512 px) and **speed** (10–300 px per second) per companion.
- **Drag** a companion, **right-click** a companion or system tray icon for actions.
- **Pause** any image, or pause all.
- **Click-through mode** lets mouse interactions pass through to apps below; disable it from the **system tray** or Settings window. Automatically disabled if the tray is unavailable.
- Handles negative monitor coordinates, side-by-side monitors, and most irregular multi-monitor edges without sending PNGs off-screen.
- Remembers image paths and settings locally, and migrates old v0.1 settings.
- Does not connect to the internet or upload images.

## Install / run the app

### Windows EXE (recommended once a release is published)

Download **`PNG-Wanderer.exe`** from the repository's **Releases** tab. Run it and choose a PNG or GIF. There is no Python requirement for the EXE.

> A Windows EXE is generated by GitHub Actions on **Windows**, not by bundling a Linux binary. This repo may have only a preview build until the first tag/release is published.

### Run the source on Windows

1. Install Python 3.10 or newer.
2. Extract or clone the project and double-click **`start.bat`**.
3. Choose a PNG or GIF with a transparent background for the best result.

Or:

```powershell
py -m pip install -r requirements.txt
py main.py
```

You can optionally pass a PNG or GIF path on the command line.

## Build an EXE on Windows

Run **`build_windows.bat`**. This installs dependencies in a local virtual environment and builds:

```text
dist/PNG-Wanderer.exe
```

Or run manually:

```powershell
py -m pip install -r requirements-build.txt
py -m pip install -r requirements-test.txt
py -m unittest discover -s tests -v
py -m PyInstaller --noconfirm --clean --onefile --windowed --name PNG-Wanderer --icon assets/app.ico --add-data "assets/app.ico;assets" main.py
```

PyInstaller needs to run **on Windows** to produce a Windows EXE. It packages Python and PySide6 into the binary.

## GitHub Actions builds and releases

The workflow in `.github/workflows/windows.yml` runs on pushes to `main` and via manual dispatch. It builds and stores an **EXE artifact** under the Actions run.

After testing and deciding it's release-ready, publish a Git tag:

```powershell
git tag v0.4.0-beta.1
git push origin v0.4.0-beta.1
```

That will trigger a new Windows build, and publish **`PNG-Wanderer.exe`** to a GitHub Release (beta tags are marked as prereleases). The workflow requires repository Actions enabled and write permissions for its `GITHUB_TOKEN`.

## FAQ

**Does it animate my PNG?** No. The image stays unchanged and only its window position moves.

**Can it cover fullscreen games?** Exclusive fullscreen or protected/elevated windows can render above desktop companions.

**Where are settings?** In the OS per-user app-config directory (`VibeCode/PNG Wanderer/settings.json`), not beside the EXE.

**If my PNG disappears?** Keep the original image in its original location, or choose it again. Missing images are skipped on launch.

**Does it collect data?** No analytics, account requirements, telemetry, image uploads, or external requests.

**License?** No redistribution license has been chosen yet. Publishing source code alone does not grant third parties permission to redistribute it. Add a license once the project owner chooses one.

## GIF playback (v0.3)

Movement speed controls desktop travel only; GIF playback stays at 100% of its encoded timing. Pause movement and dragging leave GIF playback running. Finite GIFs stop as authored; infinite GIFs repeat. Each companion owns an independent QMovie. Replacing/removing a companion stops and releases its movie. Frame masks update with transparency. Files remain local; keep originals in place.

The legacy `png_path` settings key intentionally accepts both formats, preserving v0.1/v0.2 settings without migration. No Steam integration or network feature is included in this version.

Automated tests cover animated frames, transparency, replacement, cleanup, resizing, movement modes, invalid files, persistence, and existing monitor geometry. Physical multi-monitor, tray, click-through and packaged EXE checks still require manual desktop testing; see TESTING.md.

## Desktop options (v0.4 beta)

- **Pause GIF animation** freezes playback separately from Pause movement.
- **Monitor** chooses all displays or confines one companion to a display. If that display disconnects, the primary display is used until it returns.
- **Start with Windows** is off by default. Enabling it adds the current executable (or source launcher) to the current user's Windows Run key. Keep the EXE at a permanent location, and turn the option off before deleting it.
- **Hide during fullscreen apps** is off by default. It hides all companions when the foreground window matches a monitor's native bounds and restores them afterward. Detection polls every 750 ms. Maximized borderless windows may also count; protected apps can prevent detection. Hidden companions continue their timers and GIF playback.
- **Save group / Load group** stores companions and their individual settings locally. Loading replaces the current group after confirmation; missing images are skipped. Groups reference original image paths and do not copy or upload artwork.

App preferences and groups are stored in `preferences.json` beside `settings.json`. Startup registration is stored separately in the Windows registry. `PNG-Wanderer.exe --self-test` performs an isolated offscreen GIF/settings smoke check and exits (0 on success), without changing user settings.

This beta EXE is unsigned. Windows reputation prompts may appear. No Steam integration is included. Physical multi-monitor, fullscreen/game compatibility and startup at login still need testing on each user's setup.
